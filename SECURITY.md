# Security Policy

## Supported versions

Only the current version on the `main` branch receives security fixes.

## Reporting a vulnerability

Please report suspected vulnerabilities through GitHub's private vulnerability
reporting feature for this repository. Do not open a public issue or discussion
and do not include vulnerability details in a public pull request.

Include the affected component, reproduction steps, impact, and any suggested
mitigation. Reports will be acknowledged and assessed as soon as practical.

This repository does not offer a bug bounty or guarantee a particular response
or remediation timeline.
